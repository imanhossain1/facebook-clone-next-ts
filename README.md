# 📘 Facebook Clone

A Facebook-style social media application built with Next.js, TypeScript, Tailwind CSS, and DaisyUI.

The project is being built step-by-step:
**Learn → Build → Test → Fix → Continue**

---

## 🚀 Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- DaisyUI
- MongoDB (Version 2)
- Mongoose (Version 2)
- Authentication (Version 2)

---

# 📌 Project Goal

The goal is to build a practical Facebook-style social media application.

Users will eventually be able to:

- Create posts
- View posts
- Like posts
- Comment on posts
- Manage their profile
- Add friends
- Send messages
- Login / Register
- Chat in real time
